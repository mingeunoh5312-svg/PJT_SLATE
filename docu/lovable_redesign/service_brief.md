# Slate 서비스 브리프

## 한 줄 설명

Slate는 영화와 영상 제작에 참여하는 개인 제작자, 팀, 기업, 운영자를 연결해 프로젝트 구성, 팀원 매칭, 작업물 공유, 공모전 탐색, 제작 운영을 돕는 서비스입니다.

## 서비스 목적

영상 제작 과정에서는 사람, 역할, 일정, 지역, 포트폴리오, 공모전 정보가 흩어져 있어 팀을 만들고 적절한 참여자를 찾기 어렵습니다. Slate는 제작자가 자신의 역량과 작업 이력을 정리하고, 팀이 필요한 역할을 모집하며, 서로의 조건을 기반으로 연결될 수 있도록 돕습니다.

Slate의 핵심 목적은 다음과 같습니다.

- 제작자가 자신의 역할, 경력, 관심 장르, 지역, 포트폴리오를 구조화해 보여준다.
- 팀이 프로젝트 정보, 모집 역할, 일정, 진행 상태를 관리한다.
- 제작자는 참여 가능한 팀을 찾고 지원할 수 있다.
- 팀 리더는 필요한 역할의 제작자를 찾고 초대할 수 있다.
- 작업물을 공유하고 리뷰와 반응을 통해 신뢰 가능한 활동 기록을 만든다.
- 공모전 정보를 탐색하고, 팀 또는 프로필 기준으로 준비 가능성을 검토한다.
- AI 추천과 공공데이터를 활용해 매칭, 작품 이력, 로케이션 탐색, 공모전 준비를 보조한다.
- 운영자는 플랫폼 내 회원, 팀, 콘텐츠, 신고, 기업 승인, 공모전, 권한, 로그를 관리한다.

## 사용자 유형

### 비로그인 방문자

서비스의 목적과 공개 콘텐츠를 둘러보는 사용자입니다.

주요 관심사:

- Slate가 어떤 서비스인지 이해
- 공개 작업물, 공개 프로필, 공모전 정보 확인
- 가입 또는 로그인 필요 여부 파악

### 일반 제작자

영화/영상 제작에 참여하는 개인 사용자입니다. 기획, 연출, 촬영, 조명, 음향, 미술, 편집, 배우, 색보정, VFX, 마케팅 등 여러 역할을 가질 수 있습니다.

주요 관심사:

- 프로필 작성
- 역할, 장르, 지역, 경력, 협업 조건 표현
- 포트폴리오 등록
- YouTube 작업물 또는 직접 업로드한 작업물 연결
- KOBIS 등 공공데이터 기반 참여 이력 추가
- 팀 탐색과 지원
- 팔로우와 공개 프로필 관리
- 작업물 게시와 리뷰 확인
- 공모전 저장과 제출 준비

### 팀 리더 또는 팀 관리자

작품이나 프로젝트를 진행하는 팀의 운영자입니다.

주요 관심사:

- 팀 생성과 정보 관리
- 팀 대표 이미지, 장르, 지역, 예상 기간, 정원 설정
- 모집 공고 작성
- 역할별 구인 slot 관리
- 지원자 검토와 수락/거절
- 제작자 초대와 초대 상태 확인
- 팀원 역할 관리, 리더 위임, 팀 나가기/종료
- 팀 일정과 계획 관리
- 팀 작업물 승인
- 팀 기준 AI 로케이션 후보 저장

### 기업 사용자

공모전 또는 제작 관련 모집을 개설하려는 회사/기관 계정입니다. 가입 후 관리자 승인이 필요합니다.

주요 관심사:

- 기업 계정 가입과 승인 대기
- 기업 증빙 서류 업로드
- 공모전 개설 요청
- 내가 요청한 공모전 승인 상태 확인
- 승인된 공모전 정보 수정
- 공모전 종료 요청

### 관리자

Slate 운영자입니다.

주요 관심사:

- 회원 조회, 수정, 비활성화, 복구, 제재
- 팀 조회, 수정, 숨김, 종료, 삭제, 복구
- 게시글 조회, 수정, 숨김, 삭제, 복구

- 콘텐츠 신고 처리
- 기업 계정 승인/거절과 서류 확인
- 공모전 직접 등록, 수정, 상태 변경, 일괄 삭제
- 기업 공모전 개설 요청 승인/거절
- 외부 공모전 크롤링 실행과 결과 확인
- 데모 접근 코드 관리

## 핵심 데이터 개념

### 계정

사용자의 로그인 단위입니다. 일반 사용자, 기업 사용자, 관리자 유형이 있습니다. 계정 상태는 활성, 승인 대기, 비활성 등으로 관리될 수 있습니다.

### 프로필

일반 제작자의 공개 또는 부분 공개 활동 정보입니다. 이름, 소개, 지역, 역할, 장르, 경력 수준, 참여 가능 일정, 협업 조건, 프로필 이미지, 포트폴리오 목록을 포함합니다.

### 포트폴리오

제작자가 참여한 작품 또는 작업 이력입니다. 직접 입력, YouTube URL, 업로드 파일, KOBIS/공공데이터 기반 작품 검색 결과와 연결될 수 있습니다. 역할명, 크레딧명, 작품 링크, 썸네일, 설명을 가질 수 있습니다.

### 팀

제작 프로젝트 단위입니다. 팀명, 설명, 상태, 장르, 지역, 예상 기간, 정원, 대표 이미지, 팀원, 리더, 모집 공고, 계획, 작업물 승인 흐름을 포함합니다.

### 모집 공고와 구인 slot

팀이 필요한 역할을 모집하기 위한 정보입니다. 모집 공고는 제목, 설명, 기간, 상태를 가지며, slot은 역할, 필요 인원, 남은 인원, 요구 경력, 참여 조건, 마감일 등을 가집니다.

### 지원과 초대

제작자가 팀에 지원하거나, 팀이 제작자를 초대하는 연결 요청입니다. 대기, 수락, 거절, 취소, 만료 같은 상태가 있습니다.

### 매칭 결과

팀 기준 제작자 추천 또는 제작자 기준 팀 추천 결과입니다. 역할, 장르, 지역, 경력, 일정, 협업 조건, 포트폴리오, 점수 정책, AI 추천 결과가 반영될 수 있습니다.

### 로케이션 후보

장면 설명과 지역 조건을 기반으로 추천되거나 저장된 촬영지 후보입니다. 개인 후보 또는 팀 후보로 저장될 수 있으며, 장소명, 위치, 추천 이유, 주의사항, 지도 표시 정보가 포함될 수 있습니다.

### 게시글과 작업물

커뮤니티 콘텐츠입니다. 작업물 게시글은 영상/이미지/YouTube/파일 정보와 연결될 수 있고, 자유 게시글은 공지, 질문, 정보, 후기, 자유 같은 분류를 가질 수 있습니다. 좋아요, 리뷰, 신고, 랭킹 흐름이 있습니다.

### 공모전

내부 등록 또는 외부 수집된 공모전 정보입니다. 제목, 요약, 주제, 대상, 지역, 상금, 주최, 일정, 출처, 대표 이미지, 외부 링크, 저장 여부, 제출 준비 정보, 적합도 분석 결과를 가질 수 있습니다.

### 알림

팀 초대, 지원 결과, 공모전, 게시글, 운영 알림 등 사용자의 확인이 필요한 이벤트입니다.

### 운영 기록

관리자 작업, 감사 로그, 운영 로그, 권한 변경, 정책 변경, 제재 이력 등 플랫폼 운영에 필요한 기록입니다.

## 중요한 업무 흐름

### 제작자가 팀을 찾는 흐름

1. 제작자가 프로필과 포트폴리오를 작성한다.
2. 역할, 장르, 지역, 경력, 협업 조건을 등록한다.
3. 추천 팀 또는 검색 결과를 확인한다.
4. 팀 상세와 모집 조건을 확인한다.
5. 원하는 역할로 지원한다.
6. 지원 상태를 추적한다.

### 팀이 팀원을 찾는 흐름

1. 팀 리더가 팀을 생성한다.
2. 모집 공고와 역할별 구인 slot을 등록한다.
3. 조건에 맞는 제작자 추천을 확인한다.
4. 제작자의 공개 프로필과 포트폴리오를 검토한다.
5. 제작자를 초대하거나 지원자를 수락/거절한다.
6. 팀원 역할과 팀 일정을 관리한다.

### 작업물을 공유하는 흐름

1. 사용자가 작업물 게시글을 작성한다.
2. YouTube 링크 또는 업로드 파일을 연결한다.
3. 작품 유형, 장르, 설명, 대표 이미지를 정리한다.
4. 다른 사용자가 작업물을 확인하고 좋아요 또는 리뷰를 남긴다.
5. 문제 콘텐츠는 신고할 수 있고 운영자가 처리한다.

### 공모전을 준비하는 흐름

1. 사용자가 공모전 목록을 탐색한다.
2. 조건 필터와 검색으로 관심 공모전을 찾는다.
3. 공모전 상세와 외부 원문을 확인한다.
4. 관심 공모전을 저장한다.
5. 프로필 또는 팀 기준으로 적합도를 분석한다.
6. 제출 준비 체크리스트와 메모를 작성한다.

### 기업이 공모전을 개설하는 흐름

1. 기업 계정을 만든다.
2. 관리자 승인과 서류 확인을 기다린다.
3. 승인 후 공모전 개설 요청을 작성한다.
4. 요청 상태를 확인한다.
5. 승인된 공모전을 수정하거나 종료 요청한다.

### 운영자가 플랫폼을 관리하는 흐름

1. 관리자 대시보드에서 우선 처리 업무를 확인한다.
2. 기업 승인, 신고, 파일, 회원 제재, 공모전 요청을 처리한다.
3. 필요한 경우 회원, 팀, 게시글, 공모전 상태를 조정한다.
4. 알림을 발송하거나 접근 코드를 관리한다.
5. 로그와 권한, 점수 정책을 관리한다.
