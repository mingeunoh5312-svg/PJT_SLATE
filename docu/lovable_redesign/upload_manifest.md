# Lovable 업로드 매니페스트

## 업로드할 문서

1. `lovable_prompt.md`
   - Lovable에 직접 입력할 메인 프롬프트입니다.
   - 디자인 시안 제작 범위, 금지 사항, 산출물 기준을 설명합니다.

2. `service_brief.md`
   - Slate 서비스의 목적, 사용자 유형, 핵심 데이터, 제공 기능, 주요 업무 흐름을 설명합니다.
   - 기존 UI 구조를 설명하지 않고 서비스 도메인과 기능만 전달합니다.

3. `upload_manifest.md`
   - 업로드 문서 목록과 제외 대상을 명확히 하기 위한 안내 문서입니다.

## 업로드하지 않을 항목

- 프론트엔드 소스 코드
- 백엔드 소스 코드
- SQL 파일
- 이미지 파일
- 아이콘 파일
- 동영상 파일
- 기존 화면 캡처
- 기존 UI 디자인 자료
- 기존 route 정리 문서
- API 명세 전체
- 배포 문서
- 로그 파일
- `.env` 또는 비밀값이 포함될 수 있는 파일

## 업로드 원칙

- Lovable에는 문서만 업로드합니다.
- 기존 화면의 배치나 디자인을 유추할 수 있는 자료는 업로드하지 않습니다.
- Lovable이 서비스 목적과 기능을 바탕으로 페이지 구성과 디자인 판단을 직접 수행하도록 합니다.
