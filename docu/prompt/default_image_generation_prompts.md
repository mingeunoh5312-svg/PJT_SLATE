# Slate 기본 이미지 생성 프롬프트

작성일: 2026-06-24

## 사용 목적

Slate 웹 페이지에서 사용자가 이미지를 등록하지 않았거나 외부 이미지와 YouTube 썸네일을 불러올 수 없을 때 표시할 기본 이미지 5종을 생성한다.

각 프롬프트는 웹 GPT의 이미지 생성 기능에 **하나씩 독립적으로 입력**한다. 한 번에 여러 이미지를 요청하지 않는다.

## 공통 디자인 기준

- Slate는 영화·영상 제작자, 팀, 작품, 포트폴리오, 공모전을 연결하는 제작 협업 서비스다.
- 전체 이미지는 하나의 제품에서 나온 것처럼 동일한 시각 언어를 사용한다.
- 스타일은 깔끔하고 전문적인 고급 에디토리얼 일러스트레이션으로 한다.
- 지나치게 만화 같거나 귀여운 캐릭터 스타일은 사용하지 않는다.
- 주요 색상은 코발트 블루 `#0B63F6`, 딥 네이비 `#172033`, 쿨 그레이 `#F5F7FB`, 흰색을 사용한다.
- 낮은 채도와 부드러운 시네마틱 조명, 절제된 입체감과 은은한 질감을 사용한다.
- 이미지 안에 글자, 숫자, 로고, 브랜드명, 워터마크, UI 버튼을 넣지 않는다.
- 특정 영화, 영화제, 회사, 카메라 브랜드, 플랫폼을 연상시키는 상표를 넣지 않는다.
- 식별 가능한 실제 인물이나 유명인을 만들지 않는다.
- 작은 카드에서도 주제가 명확하도록 주요 피사체를 단순하게 구성한다.
- 반응형 화면에서 일부가 잘려도 의미가 유지되도록 핵심 요소를 중앙 안전 영역에 배치한다.
- 생성 결과는 가능한 최고 해상도로 내려받은 뒤 지정 크기로 리사이즈하고 WebP로 변환한다.

### 저장 정보

- 저장 경로: `frontend/src/assets/defaults/default-profile.webp`
- 최종 크기: `800 × 800px`
- 비율: `1:1`

### 생성 프롬프트

```text
Slate라는 영화·영상 제작 협업 웹 서비스에서 사용할 프로필 기본 이미지를 한 장 생성해 주세요.

정사각형 1:1 구도이며, 실제 사용자가 프로필 사진을 등록하지 않았을 때 표시되는 중립적인 기본 이미지입니다. 성별, 나이, 인종을 특정할 수 없는 추상적인 사람의 상반신 실루엣을 중앙에 배치해 주세요. 얼굴의 눈, 코, 입을 사실적으로 묘사하지 말고, 부드러운 곡면과 빛으로 사람의 형태만 암시해 주세요.

원형 아바타와 둥근 사각형 카드 양쪽에서 모두 자연스럽게 잘릴 수 있도록 인물 형태를 이미지 중앙 65% 안에 배치하고, 머리 위와 어깨 주변에 충분한 여백을 남겨 주세요. 배경은 밝은 쿨 그레이와 아주 옅은 블루 그라데이션으로 구성하고, 코발트 블루 #0B63F6와 딥 네이비 #172033를 절제된 포인트로 사용해 주세요.

스타일은 전문적이고 차분한 고급 에디토리얼 일러스트레이션이며, 부드러운 시네마틱 조명과 은은한 입체감을 사용합니다. 채용 사이트의 평범한 회색 사람 아이콘처럼 보이지 않으면서도 실제 인물 사진으로 오해되지 않아야 합니다.

이미지 안에 글자, 숫자, 로고, 브랜드명, 워터마크, 테두리, UI 요소를 넣지 마세요. 유명인이나 식별 가능한 실제 인물을 만들지 마세요. 과도하게 귀엽거나 만화 같은 캐릭터 스타일, 여권 사진 스타일, 강한 표정은 피하세요.

최종 결과는 800×800px로 사용하기 적합한 고해상도 이미지여야 합니다.
```

### 확인 기준

- 원형으로 잘라도 머리와 어깨가 잘리지 않는다.
- 특정 성별이나 연령으로 강하게 보이지 않는다.
- 실제 회원 사진과 명확히 구분되는 기본 이미지다.

## 생성 결과 공통 검수

1. 5개 이미지가 동일한 색상과 일러스트레이션 스타일을 사용하는지 확인한다.
2. 글자처럼 보이는 무작위 기호나 깨진 문자가 없는지 확인한다.
3. 로고, 워터마크, 실제 브랜드, 특정 작품을 연상시키는 요소가 없는지 확인한다.
4. 지정 비율로 크롭했을 때 핵심 피사체가 잘리지 않는지 확인한다.
5. 작은 카드에서 이미지의 용도가 구분되는지 확인한다.
6. 프로필 이미지는 원형 크롭, 나머지 이미지는 16:9 크롭으로 확인한다.
7. WebP 변환 후 색상 깨짐, 심한 압축 노이즈, 투명 영역 문제가 없는지 확인한다.
