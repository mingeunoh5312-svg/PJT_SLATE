# 2026-06-24 매칭 페이지 필터/기준 팀 구인 현황 수정 정리

## 문서 작성 기준

- 사용자 지시가 명시한 매칭 페이지 범위만 정리한다.
- 점수 계산, AI 추천 정책, API 계약, 필터 항목 추가/삭제처럼 사용자가 지시하지 않은 정책 변경은 작업 범위에서 제외한다.
- 사용자 지시로 구현한 내용과 검증 결과를 구분해 기록한다.
- 미확인 또는 이번 지시 범위를 벗어난 `todo.md` 항목은 완료로 표시하지 않는다.

## 작업 범위

- 대상 화면: 매칭 페이지의 팀원 찾기/팀 찾기 필터 영역
- 주요 파일:
  - `frontend/src/views/MatchingView.vue`
  - `frontend/src/styles/slate.css`
  - `backend/src/main/java/com/slate/matching/MatchingService.java`
  - `backend/src/test/java/com/slate/matching/MatchingServiceTeamToMembersTest.java`
- 주요 검증 대상:
  - 기준 팀 선택과 기준 팀 구인 현황
  - 지역/장르/경력/작업 일정/모집 역할 필터 UI
  - 복수 선택 필터 query/API/backend 처리
  - 초기화 시 기존 결과 유지
  - AI 추천/팀원 검색 버튼 배치
  - 결과 없음/로딩/오류 상태 분리

## 반영 내용

### 기준 팀 구인 현황

- 기준 팀 선택 항목은 유지했다.
- 기존 기준 팀 옆 `모집 역할` 선택 영역을 기준 팀 아래의 `기준 팀 구인 현황`으로 재배치했다.
- 구인 현황은 모집 중인 역할, 일정 정보, 잔여 인원수를 역할별 한 줄로 표시하도록 구성했다.
- 김도윤 사용자가 기준 팀을 `남산 새벽팀`으로 선택했을 때 구인 현황이 계속 로딩 상태로 남던 문제를 수정했다.
- 원인은 구인 현황 렌더링 중 공통 라벨 함수가 `ref`/`computed` 값을 배열처럼 처리해 화면 렌더링이 중단되는 문제였다.

### 필터 UI

- 필터 선택 방식을 표 형식으로 정리했다.
- 첫 줄은 지역과 경력을 두 단으로 배치했다.
- 장르, 경력, 작업 일정, 모집 역할은 체크박스 기반 복수 선택 방식으로 변경했다.
- 모집 역할 필터는 기준 팀 구인 현황의 역할과 겹치더라도 별도 필터로 유지했다.
- 선택한 필터는 칩 형태로 표시하고 개별 제거가 가능하도록 유지했다.

### 지역 입력

- 지역은 텍스트 입력창 아래에 검색 결과가 펼쳐지는 방식으로 수정했다.
- 입력 중인 텍스트를 포함하는 지역이 하단에 출력되도록 했다.
- 지역 항목 클릭 시 선택되도록 수정했다.
- 선택된 지역 표시가 `정보 없음`으로 표시되던 문제를 지역 표시명(`publicDisplayName`)을 사용하도록 보정했다.
- 입력창이 활성화된 상태에서 입력값이 비어 있으면 전체 지역 목록을 출력하도록 수정했다.
- 입력창이 비활성화되면 지역 목록이 닫히도록 수정했다.
- 지역 선택 후에는 입력값을 비우되 입력창 활성 상태에서는 전체 지역 목록을 계속 확인할 수 있도록 수정했다.

### 필터 초기화와 결과 유지

- 초기화 버튼은 추가 필터만 초기화하도록 정리했다.
- 기준 팀과 기준 팀 구인 현황 선택은 초기화 대상에서 분리했다.
- 초기화 시 이전 검색 결과가 즉시 갱신되지 않도록 했다.
- 초기화 후 검색 버튼을 눌렀을 때 초기화된 조건으로 다시 조회되도록 했다.

### 필터 적용

- 복수 선택 필터가 프론트 query, API 요청 파라미터, 백엔드 필터 처리에서 일관되게 동작하도록 확인했다.
- 모집 역할을 `영상 편집`으로 선택한 뒤 팀원 검색 시 `roleIds=22`가 요청에 포함되도록 확인했다.
- 해당 조건에서 촬영감독/카메라 오퍼레이터 결과가 섞여 나오던 문제를 수정했다.

### 버튼 배치

- `AI 추천` 버튼은 추천 인재/추천 팀 결과 블럭 헤더의 오른쪽에 배치했다.
- `팀원 검색` 버튼은 필터 액션 영역의 가장 오른쪽에 배치했다.
- `초기화` 버튼은 필터 액션 영역 왼쪽에 유지했다.

## 검증 결과

- 프론트엔드 빌드:
  - `npm run build` 통과
- 백엔드 테스트:
  - `mvn -Dtest=MatchingServiceTeamToMembersTest test` 통과
- 브라우저 확인:
  - `김도윤` 로그인 기준, 팀원 찾기에서 기준 팀 `남산 새벽팀` 선택 시 `촬영감독`, `동시녹음`, `영상 편집` 구인 현황이 표시됨
  - `구인 현황을 불러오는 중입니다.`와 `선택 가능한 모집 역할이 없습니다.` 문구가 동시에 남는 문제 해소
  - `영상 편집` 필터 적용 시 요청 URL에 `roleIds=22` 포함 확인
  - 필터 초기화 시 새 검색 요청 없이 기존 추천 인재 결과 유지 확인
  - 지역 입력 포커스 시 전체 목록 출력, 입력 시 포함 검색, 선택 시 선택값 반영 확인

## 이번 작업에서 의도적으로 변경하지 않은 내용

- 매칭 점수 계산 로직은 변경하지 않았다.
- AI 추천 정책과 추천 후보 선정 정책은 변경하지 않았다.
- API 계약 자체는 변경하지 않았다.
- 사용자가 지시하지 않은 필터 항목 추가/삭제는 하지 않았다.
- 팀 페이지, 메인 페이지, 공통 안내/이미지 정책 등 `todo.md`의 다른 대분류 작업은 이번 완료 범위에 포함하지 않았다.

## 남은 확인 사항

- `todo.md`의 매칭 페이지 항목 중 장르 자동완성 방식처럼 이번 사용자 지시의 체크박스 방식과 다른 항목은 별도 사용자 확인 후 진행해야 한다.
- 지역 전체 목록 출력은 데이터 수가 많아질 경우 스크롤 높이와 성능을 추가 확인할 필요가 있다.
- 실제 사용자 브라우저에서 dev 서버 캐시가 남아 있으면 새로고침 후 확인이 필요하다.
