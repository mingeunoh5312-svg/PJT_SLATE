## 반영 내용

### 공통 레이아웃과 좌측바

- 상단의 `김도윤 프로듀서님 환영합니다.` 영역에 생긴 흰색 배경을 제거해 이전의 투명한 상태로 되돌렸다.
- 데스크톱 페이지 구성 최대 폭을 `1920px` 기준으로 맞추고, 1920px 초과 구간에서 중앙 정렬이 아니라 좌측 정렬로 배치되도록 정리했다.
- 좌측바 하단 유저 정보 영역 클릭 시 내 프로필 화면으로 이동하도록 동작을 연결했다.
- 좌측바의 텍스트 이모티콘 사용을 줄이고 Slate 로고 우측 및 메뉴 좌측에 이미지가 들어갈 수 있는 구조로 바꿨다.
- 좌측바 이미지 업로드와 표시에서 이미지 배경색이 좌측바보다 어둡게 보이던 원인을 이미지 래퍼와 활성 상태 배경 처리로 보고, 이미지 자체에는 배경색이 직접 지정되지 않도록 조정했다.
- 좌측바 이미지가 선택 영역 대비 작게 보이던 문제를 줄이기 위해 표시 크기를 키웠다.
- 공동 작업자 브랜치 `dev_Slate_0625_user2_visual`의 서비스 운영용 이미지와 폴더 구조를 현재 프로젝트에 이식했다.
- 사이드바 이미지 설정에서 `localStorage` quota를 초과하던 `slate.sidebar.assets.v1` 저장 문제를 줄이도록 저장 구조와 자산 처리 흐름을 조정했다.

### 홈

- `내 활동 현황` 영역의 과도한 높이를 줄였다.
- 같은 기준으로 `지금 확인할 활동`, `마감 임박 공모전`, `최근 등록된 작업물`의 불필요한 여백을 줄였다.
- 홈 상단 파란 버튼의 텍스트 오른쪽에 생기던 불필요한 공백을 제거했다.
- 마감 임박 공모전 카드에서 특정 제목 길이에 따라 `상세 보기` 버튼 크기가 달라지는 문제를 고정 크기 버튼 영역으로 보정했다.
- 버튼 하단 여백이 생기던 문제는 공모전 이미지 영역 높이를 늘려 카드 내부 균형을 맞췄다.
- 최근 등록된 작업물의 `MANUAL` 표기를 운영 단계에 맞지 않는 고정값으로 보지 않고 게시글 분류에 따라 표시되도록 수정했다.

### 매칭

- `기준 선택`, `조건 조정`, `후보 검토` 블럭과 최상단 안내 블럭을 제거해 실제 검색과 추천 결과 중심으로 재구성했다.
- 팀이 없는 상태에서도 팀원 찾기에 진입하고 전체 공개 유저를 조회할 수 있도록 수정했다.
- 기준 팀 구인 현황의 기본값을 선택되지 않은 상태로 두고, 팀 선택 시 기존 기준 팀 기반 동작을 유지하도록 했다.
- 기준 팀이 없을 때는 하단 필터로 검색하거나 이전 검색 결과를 유지하도록 흐름을 보정했다.
- 팀이 없는 상태에서 출력되던 `기준 팀과 모집 역할이 필요합니다.` 안내를 제거했다.
- 추천 인재 문구를 `추천 팀원`으로 바꾸고, 기본 추천은 전체 공개 프로필을 프로필 수정 최신순으로 반환하도록 정리했다.
- 모든 검색 결과에서 적합도 표시가 누락되던 문제를 보정하고, 팀이 없어 계산할 수 없는 경우에는 `선택된 팀이 없습니다.` 또는 `적합도를 계산할 수 없습니다.`처럼 상황에 맞는 문구를 표시하도록 바꿨다.
- 적합도 계산 불가 문구의 과도한 크기와 뒤에 남는 적합도 표기를 정리했다.
- `AI 팀 추천`, `AI 팀원 추천` 블럭 디자인을 재구성하고 추천 버튼 클릭 시 별도 내부 버튼을 다시 누르지 않아도 즉시 결과를 반환하도록 했다.
- AI 추천 결과 하단의 `추천 사유:` 접두 문구와 불필요한 안내 문구를 제거하거나 요청 문구로 교체했다.
- AI 추천을 받아도 기존 검색 결과가 추천 블럭 하단에 유지되도록 했다.
- `후보 상세`, `팀원 후보 상세`, `팀 후보 상세` 문구를 각각 `프로필 보기`, `팀 정보 보기`로 정리했다.
- 팀 후보 상세에서 지원 취소, 저장 취소 등 이벤트 후에도 상세 상태가 남아 있던 문제를 동기화하고 불필요한 상태 토스트 텍스트를 제거했다.
- 지원한 팀, 저장한 팀, 초대한 팀원, 팀원 후보 상세에서도 적합도와 지원·초대 상태가 일관되게 보이도록 보정했다.
- 팀원 찾기와 팀 찾기 검색 결과에 5개 단위 페이지네이션을 추가하고, 페이지 버튼은 중앙 정렬 및 `처음`·`마지막` 버튼을 포함하도록 정리했다.
- 초대한 팀원 탭의 `ACTIVE` 체크박스를 제거했다.
- 팀원 후보 상세의 `초대/초대됨` 버튼 크기를 팔로우 버튼 크기와 맞추고 팔로워 수 텍스트를 제거했다.

### 팀

- 팀 목록 최상단 블럭의 제목을 `내 팀 요약`으로 바꿨다.
- `진행 중`, `종료됨` 영역 폭을 줄이고, 세 번째 영역을 `해야 할 작업`으로 바꿨다.
- 해야 할 작업은 지원/초대 대기, 다음 팀 계획 등 사용자가 처리할 가장 가까운 업무를 반환하고 클릭 시 해당 팀 또는 관련 페이지로 이동하도록 했다.
- 내 팀 요약 블럭의 여백을 줄여 높이를 낮췄다.
- 종료된 팀 블럭의 빈 상태 텍스트 시작 위치가 제목과 맞도록 정렬을 보정했다.
- 팀 정보 화면의 `리더 OOO` 클릭 시 해당 유저의 공개 프로필로 이동하도록 했다.
- 팀 정보 화면의 리더, 지역, 정원 텍스트 박스에 동일한 연한 색조 배경을 적용했다.
- 멤버 영역의 `(최대 정원 N명)` 문구를 `(최대 N명)`으로 수정했다.
- 팀 멤버 화면에서 `팀 목록` 버튼을 제거하고, 상세 버튼 텍스트를 `돌아가기`로 바꾸며 우측 정렬했다.
- 팀 정보 화면의 `모집 공고`와 `지원/초대 현황` 진입을 분리했다.
- `지원/초대 현황` 페이지는 `지원 대기`와 `초대 대기`를 별도 상하단 블럭으로 나누고 각각 페이지네이션을 적용했다.
- `모집 공고` 페이지는 공고 요약, 공고 목록, 공고 편집, 모집 슬롯 편집이 분리되도록 재구성했다.

## 의도적으로 완료 범위에 포함하지 않은 항목

- 게시판, 공모전, 내 정보, 관리자, 로그인, 회원가입 페이지의 전면 디자인 재구성은 아직 진행하지 않았다.
- 메인 카드 디자인 변경은 사용자 요청에 따라 롤백 대상이었으므로 추가 확장하지 않았다.
- 매칭과 팀 관련 API 계약은 필요한 범위에서만 보정했고, DB 스키마 자체 변경은 진행하지 않았다.
- 실제 운영 이미지의 최종 디자인 선정은 이번 구현 범위가 아니라 업로드 가능한 구조와 자산 경로 반영까지만 처리했다.
- 실제 DB 데이터와 로그인 계정으로 지원/초대/저장/AI 추천 전체 E2E 검증은 남아 있다.

## 남은 확인 사항

1. 5174, 8080 서버를 최신 코드로 재시작한 뒤 홈, 매칭, 팀 페이지를 실제 로그인 계정으로 확인한다.
2. 매칭의 팀 없는 팀원 검색, AI 추천 즉시 반환, 지원/저장/초대 상태 동기화를 실제 DB 데이터로 재확인한다.
3. 팀의 모집 공고와 지원/초대 현황 분리 페이지를 팀장 계정과 일반 계정으로 각각 확인한다.
4. 좌측바 이미지 업로드 후 활성/비활성 상태에서 배경색이 직접 적용되지 않는지 브라우저에서 확인한다.
5. 남은 페이지 순서인 게시판, 공모전, 내 정보, 관리자, 로그인, 회원가입 전면 재구성을 별도 작업 로그로 이어간다.
