# 수정 사항 정리
# 게시판 문제점
1. 홈화면에서는  검색할 수 있는 기능이 없습니다. 홈화면에서 작업물, 자유 게시판을 필터로 나눠서 검색할 수 있도록 하세요
2. 하드 코딩된 부분들을 전부 DB 와 연동해서 데이터를 가져올 수 있도록 수정해주세요
3. 현재 현재 상단에 작업물 버튼을 누르지 않았는데도 불구하고 해당 부분이 해당 부분이 눌러져있는 상태로 되어있습니다. 이를 수정하세요
4. 추천 작업물의 경우에는 이미지는 유튜브 썸네일이나 사용자가 직접 이미지를 업로드 할 수 있도록 수정해주세요
5. 내 업로드 파일 관리 와 팀 작업물 승인 버튼의 경우에는 오른쪽 상단에 글쓰기와 작업물  버튼과 동일한 크기로 그 옆으로 옮겨주세요
6. 인기 작업물의 순위가 좋아요 개수로 순위가 결정되고 이게 프런트 화면에서 그대로 잘 출력이 되는 지 확인하세요
7. 인기 프로필의 경우 팔로워/팔로잉 순위에 따라 결정되고 이게 프런트 화면에서 그대로 잘 출력이 되는 지를 확인하세요
8. 인기 작업물에서 특정 작업물 이름 클릭시 해당 작업물의 작업물의 상세로 들어갈 수 있도록 수정하세요
9. 인기 프로필에서 특정 프로필  이름클릭시 해당 상세 프로필로 들어갈 수 있도록 수정하세요
10. 프로필 옆에 팔로우 버튼을 생성해서 팔로우 할 수 있도록 합니다. 버튼 모양은 하트로 합니다.
11. 작업물 페이지에서 검색 부분이 페이지 하단에 있는데 이를 수정할 홈화면과 동일하게 페이지 상단으로 갈 수 있도록 수정하세요 .
12. 작업물 페이지에서 자유 게시판 부분도 같이 보이고 있습니다. 작업물 클릭시에는 작업물과 추천 작업물들만 보일 수 있도록 수정하세요. (인기 작업물과 인기 프로필은 계속 보여도 상관 괜찮습니다.)
13. 정렬 기능도 구현해서 페이지 상단에 만듭니다.
14. 자유 게시판의 경우에는 검색 기능이 없습니다. 수정 할 홈화면과 작업물 게시판과 동일하게 페이지 상단에 검색 기능이 구현될 수 있도로록 수정하고 정렬 기능도 상단으로 이동 시킵니다.
15. 자유 게시판은  상세 항목이 필요합니다. 항목은 공지, 질문, 정보,후기, 자유 총 5가지로 나뉩니다. 이를 추가하세요
16. 인기 게시판의 경우에는 일, 주, 월, 년 항목을 삭제하고 좋아요 순으로 작업물을 볼 수 있도록 합니다.  이때도 작업물 종류 별로 항목을 나눠서 볼 수 있도록 기능을 구현합니다.
